# Письма-отзывы водителям

Шаблоны письма «как вам у нас работается» для компаний на HR-портале (`<компания>.mycarrierlink.com`).
Витрина с предпросмотром: https://miron-droid.github.io/driver-review-emails/

## Как устроено
- `companies.json` — все компании: название и логотип из портала, цвет, ссылка Google сразу в окно оценки (если в портале есть), картинки.
- `img/<тенант>/` — `hero.jpg` (шапка письма и страницы), `done.jpg` (экран «спасибо»), логотип, `logo-mail.png` для писем. Картинки сделаны в Higgsfield, у каждой компании свой стиль.
- `_base/template.html` + `build.py` — из них собираются письма: `python3 build.py` пишет `<тенант>/template.html` (вставлять в портал) и `<тенант>/preview.html`.
- `tls/template.html` сделан руками (подпись Hazel, телефон, адрес), сборщик его не трогает.
- `page/index.html` — общая страница опроса для всех компаний, `?c=<тенант>&r=1..5`.

Плейсхолдеры: `{first_name}` `{name}` `{company}` `{link}` `{loads}` `{logo_url}`. Неизвестный `{...}` остаётся в письме как есть.

## Правила вёрстки
- Только таблицы и инлайн-стили, ширина 600px, читается на 360px.
- Картинки на HTTPS-домене компании, у `<img>` заданы width и height в правильной пропорции и есть alt.
- Кнопки ответа одинаковые по цвету, чтобы не подталкивать водителя к хорошему ответу.
- Ничего не обещаем (бонусов, денег за отзыв).

## Новая компания
1. Картинки `hero.jpg` (1200×500) и `done.jpg` (1200×545) в `img/<тенант>/`, логотип туда же, `logo-mail.png` высотой 160px.
2. Строка в `companies.json`.
3. `python3 build.py`, закоммитить.
